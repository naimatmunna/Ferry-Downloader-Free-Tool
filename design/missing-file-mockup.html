Ferry: when a file is gone Mockup

No more .json files on iPhone

A mockup for your OK. Nothing in the app has changed yet. Dashed outlines show what’s new.

What changes

  • Tap Save: Ferry first checks the file is still on the server.
  • If it’s gone: a message in Ferry with “Download again”, which gets the same file with the same choices. The card says “Deleted from server”.
  • If something still slips through: the phone shows a short page with “Back to Ferry”, never a .json file.
